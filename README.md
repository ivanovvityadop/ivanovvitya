# Victor Ivanov portfolio

The live GitHub Pages source is the `202602_MAIN_01` branch.

## Site structure

- `index.html` redirects the domain root to the current Motion page.
- `stills.html` preserves the old Stills URL and redirects to the current page.
- `preview/index-v2.html` is the current Motion portfolio.
- `preview/stills.html` is the Stills album index.
- `preview/album.html` renders an individual album.
- `preview/albums-data.js` controls album names, ordering and photographs.
- `preview/stills.css` contains shared Stills and album styles.
- `preview/site-panels.js` controls the shared About and Contact panels.
- `store.html` is the separate TrueScan store page.
- `thumbs/` contains Motion and store media.
- `preview/film01/` and `preview/film02/` contain Stills photographs.

Edit the files under `preview/` for the current portfolio. Keep `CNAME`, the two root redirects and `store.html` unless the domain or site structure is intentionally changing.
